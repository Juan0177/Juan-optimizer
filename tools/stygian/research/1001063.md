## 1. Fight cycle (Fearless/Dire)

The fight repeats a **75 s** cycle (AI skill 253 "StateChange", group 2, `DPCBHDLNMJO: 75`, no initial CD):

| t (s, cycle-relative) | state | RES | FM / AC | source |
|---|---|---|---|---|
| 0 → ~2.5 (est.) | StateChange (transforming) | ≥270% (see §3) | frozen | skill 253; `StageChange_ExtraSubHurt` |
| ~2.5 → ~5 (est.) | Super_Rush (blinks to arena centre) + RotateAtk_BS | ≥270% | frozen; FM reset to 32, AC to 0 | `Monster_DragonCollar_Rush.BlinkLogic2` (to `InitialPos`), `StageChange_ParamReset` |
| ~5 → ~57.5 | **Sweeper loop** (RotateAtk_Loop, or ThunderAtk_Loop after Counterstrike): the dynamic part (§2) | 270 / 110 / 30 (Cryo −30) | FM and AC run | §2 |
| ~57.5 | Super ends: `Monster_DragonCollar_SuperCountdown` (duration `RotateTime` = **55 s**, from entering pose 202 at the end of StateChange) expires → `SuperSkillEnd`, back to pose 201 | | | ShieldManager specials `RotateTime: 35`, overridden to 55 by `Monster_DragonCollar_SetValue_LeyLineChallenge` when High |
| ~57.5 → 75 | **Normal mode** (melee, vortex, charge, trap-and-bomb) | **80%** all, or **10%** all if in this Super it was ever stopped (FM ≤ 10) or ever went into Counterstrike | none | `SubHurtDeltaManager`: `SubHurtDeltaState` 0 → `NormalSubHurt` (`InCombatNormal_SubHurtDelta` 0.7), 1 → `BonusSubHurt` (0) |
| 75 | next StateChange (cycle repeats: FM 32, AC 0) | | | |

- Per cycle: ~5 s transition (≈7%), ~52.5 s loop (≈70%), ~17.5 s normal (≈23%). Only the 75 s and 55 s are in the files; the ~2.5 s
  StateChange and ~2.5 s Super_Rush + RotateAtk_BS are **estimates** (animation lengths are not in the dump). Model them as a parameter
  (`entry ≈ 5`), as `MOONGECKO.entry` is.
- Cycle 1 starts at combat start: group 2 has no initial CD, and `Monster_DragonCollar_AbyssVersion_SkillOnce` fires the animator trigger
  `AbyssVersionOnce` 0.1 s after spawn. I assume the 75 s CD runs from that first cast; the CD/Super pairing (overworld 70/35, Abyss 55/35,
  Fearless/Dire 75/55: always about 20 s between Supers) supports it. If the first transform did not start the CD, the second Super would
  follow the first almost at once (no ~17 s normal window in cycle 1). Medium confidence.
- If the CD comes up mid-attack, the StateChange waits until that normal-mode attack ends (≤ ~2 s slip; not in the files).
- Lower Stygian difficulties (not High, for reference): group 1, StateChange CD 55 s, Super 35 s, FM −4 per Cryo hit.

## 2. The Sweeper loop: Flow Momentum and Counterstrike

### 2a. Flow Momentum (modifier `Monster_DragonCollar_IceDetect`, attached only in states RotateAtk_Loop and ThunderAtk_Loop)

- Start **32** each Super (`ChargeBarInitialValue: 32`; `StageChange_ParamReset` sets it back to 32 at each StateChange). Max **135**
  (`ICKDPKAIMKM: 135`), min 0 (assumed clamp).
- Gain: **+2 every 0.4 s** (= 5/s): `AIHECAMKEFK: 0.4`, onThinkInterval `+2` while `ReadyToDetect == 1`. FM only moves in the two loops.
  `ReadyToDetect` is 0 during StateChange, RotateAtk_BS, SwitchMode, ThunderAtk_BS and ThunderAtk_AS, and 1 after them.
- Cryo: **−3 per Cryo DMG instance** when High (−4 otherwise). onBeingHit, predicates: hit element `Ice` (`PHPPGPAKJFG`) + `CGLJECJBFGG
  {DECGLBMMIFE:true}` + `ReadyToDetect == 1`. Inner branch: `LeyLineChallenge_MonsterLevelHigh` NoneOrEqual → −4, else −3.
  - **Per hit, no ICD, no gauge condition.** There is no element-durability predicate (`AFAFNIMFOCD`) and no cooldown. Wavebinder's Electro
    counter uses the same `PHPPGPAKJFG` element check, and there 0-durability hits count as well. `CGLJECJBFGG` is not decoded (also used on
    Snegurochka's star shield). It reads as a generic "real damage hit" filter, not an element-application filter. Confidence: medium-high.
  - Cryo **reaction** damage (Superconduct, Cryo Swirl) probably counts, since its hit element is Cryo. Not verified.
  - Cryo hits during the transitions and in normal mode do nothing.
- Speed / beam levels (`RotateSpeedLV0..4`, thresholds `[-0.5, 10.5, 30.5, 60.5, 120.5, 135.5]`): 0–10 **stopped** (speed 0, no beams,
  effect `IceStop`); 11–30 slow; 31–60; 61–120; 121–135 adds 2 extra beams. The same thresholds drive the Counterstrike laser follow speed
  (`ThunderAtk_Follow.LaserFollowControl`): FM ≤ 10 stops the tracking rays too.
- **Stopped = FM ≤ 10 (integer FM 0–10).** There is no timer: the boss stays in its loop and FM keeps gaining +2 per 0.4 s. It stays
  stopped only while the team keeps it down. Break-even is 5/3 Cryo hits per second (stygian.moe: "keep dealing Cryo DMG at a higher
  frequency than once per 0.6 s").
  - Uniform Cryo rate r > 5/3/s: time from loop start to the first stop ≈ 22 / (3r − 5) s (r = 2 → 22 s; 2.5 → 8.8 s; 3 → 5.5 s; 4 → 3.1 s;
    5 → 2.2 s). After that it stays stopped while the rate holds.
  - After the last Cryo hit it recovers within ceil((11 − FM)/2) × 0.4 s: 2.4 s from 0, 0.4 s from 10.
  - Left alone, FM reaches 135 about 20.8 s into the loop (52 ticks). From 135, 125 net must come off: 125 / (3r − 5) s.
  - Best modelled as a tick simulation on the rotation's Cryo hit timestamps: loop-relative ticks every 0.4 s (+2), −3 per Cryo instance,
    clamp [0, 135], stopped iff ≤ 10.
- The first stop of each Super (High only) drops 2 orbs (`GGHAMMBFANB` ×2, config 2024, `PNCKIFJBHAP: 18`): the wiki and stygian.moe
  both say **36 base energy**. `_FALL_ENERGEY` is reset in `SuperCountdown` onAdded, so this happens **once per Super phase**. That matches
  the game text ("each time it enters Sweeper Mode"); the wiki says "once per combat" (wrong).

### 2b. Forced Counterstrike (AC, modifier `Monster_DragonCollar_ShieldManager`, attached in poses 202/203)

- Mixin `KNFKCEBNCKC` (interval `OALHLCECGHM: 1` s): **+30** when the character **enters** Nightsoul's Blessing (`HOIFKFGEOHO`) and
  **+10 each second** it is kept (`JIICKDJOGFI`). Max **180**. Both need `ReadyToDetect == 1` (only in the loops) and
  `_MONSTER_DragonCollar_ChargeFull` unset (never set in these files; assume unset).
  - Decoding check: DragonClaw (Configuration Device) uses the same mixin, with `UNIQUE_NyxStateKeeping_Eff` on the per-second list and
    `DragonizedEnter` on the entry list. Wiki for the Overseer: "30 points … when a character enters NB, and 10 points … every second NB is
    maintained", max 180. They agree.
  - "Active character": the game text says so; the predicate `OGAIHKLIALG` is not decoded. Use the on-field NB uptime.
  - **Cumulative, never decays** within a Super: only `StageChange_ParamReset` (each StateChange) zeroes it. Every re-entry adds 30.
    An entry during a transition is lost (`ReadyToDetect` 0).
  - Seconds of on-field NB needed: 15 s after an entry inside the loop (30 + 15×10), or 18 s if already in NB when the loop starts (no entry
    event). In general, full when 30 × (entries in loop) + 10 × (NB seconds in loop) ≥ 180.
- At 180: `SubHurtNyxRemove` is attached at once (value ≥ 179.5), so RES drops immediately. `NyxStateMonitor_Full` then fires
  `RotateToThunder` → SwitchMode + ThunderAtk_BS (~2 s est., FM frozen, Cryo ignored) → ThunderAtk_Loop (tracking rays; High: `AtkInterval`
  0.5 → 0.3 and the "Plus" laser set = the "more powerful rays").
- Counterstrike lasts until the Super ends (same 55 s countdown). There is no way back to Sweeper in that Super.
- "A certain number of Cryo instances stops it" = the same FM counter: in ThunderAtk_Loop FM keeps +2/0.4 s and −3 per Cryo hit, from its
  value at the switch (saved on leaving RotateAtk_Loop and reloaded). **Hits needed ≈ (FM_at_switch − 10 + 5·t) / 3** over t seconds
  (e.g. non-Cryo team going full at 18 s into the loop: FM ≈ 122 → 112 net to remove).
  The wiki adds "needs FM ≥ 10 to switch". If AC fills while stopped, the RES is the same either way (lv3 = lv2 when High), so it only
  delays the switch animation.
- AC filling, or any stop, sets `SubHurtDeltaState = 1`, which makes the following normal mode **10%** instead of 80%.

## 3. RES in every state (Fearless/Dire; base 10% all from the monster table, plus the High deltas)

`SubHurtLevel = 2·[FM ≤ 10] + 1·[AC = 180]` (`Monster_DragonCollar_SubHurtManager`; `SubHurtIceRemove` +2, `SubHurtNyxRemove` +1).
Deltas: ShieldManager `abilitySpecials`, overridden when High by `Monster_DragonCollar_SetValue_LeyLineChallenge`.

| state | delta (default → High) | Fearless/Dire RES | wiki | stygian.moe | repo now |
|---|---|---|---|---|---|
| Sweeper (lv0) | `inbattle_lv0` 2 → **2.6** | **270%** all | 270% | Enhanced 270% | enhanced 270 ✓ |
| Stopped, FM ≤ 10 (lv2) | `lv2` −0.1 → **0.2**; Cryo also `icebonus_lv2lv3` −0.4 and `IceBonus` 0 → **−0.2** | **30%** all, **Cryo −30%** | 30 / −30 | Low Power 30 / −30 | lowEnergy ✓ |
| Forced Counterstrike (lv1) | `lv1` 0.4 → **1.0** | **110%** all | 110% | Nightsoul 110% | nightsoul ✓ |
| Counterstrike stopped (lv3) | `lv3` −0.1 → **0.2**; same Cryo extra | **30%** all, **Cryo −30%** (= lowEnergy) | — | — | missing (reuse lowEnergy) |
| Normal mode, never stopped/countered this Super | `InCombatNormal_SubHurtDelta` 0.7 (no High override) | **80%** all | "in some domains like Spiral Abyss … 80% after Sweeper Mode" | — | **missing** |
| Normal mode after a stop or Counterstrike | `InCombatBonus_SubHurtDelta` 0 | **10%** all | — | — | **missing** |

| Transition: Super_Rush (pose 202) | ExtraSubHurt + SubHurtLevel0, if they stack additively | up to 530% | — | — | treat as enhanced |
| Before aggro (StatueMode, Abyss variant) | `before_battle` 3 | 310% | — | — | ignore |

- Cross-check of the default values: the wiki's overworld table (Sweeper 210%, stopped 0% / Cryo −40%, Counterstrike 50%) equals
  10% + the un-overridden deltas, which confirms the reading.
- All 8 types (Physical included) take the same delta. Only Cryo gets the extra in lv2/lv3.
- Nothing in the files makes it invulnerable. There is no HP-threshold phase and no poise/break mechanic (`Actor_EndureDelta` only in
  pre-battle StatueMode). HP 75/50/25% only drop ordinary orbs (`hpDrops` 22010030). No Stellar Glimmer, healing or reaction-count checks.

## 4. Model in terms of what the team model knows

Inputs used: DPS by element (rescaled per RES), Cryo DMG instances per second + timestamps, on-field NB uptime + timing (entries and
held seconds), opening (no energy). Unused: gauge (ICD), Stellar share, reactions other than Cryo-element ones, poise, healer.

Per cycle k (start `c = 75k`):
1. `[c, c+E)`, E ≈ 5 (est.): transition at enhanced RES (270%; little damage lands).
2. Loop `[c+E, c+2.5+55)`: play the rotation (its phase continues from the fight clock). Simulate on 0.4 s ticks:
   - `FM += 2` per tick, `−3` per Cryo instance, clamp [0, 135]; FM starts at 32.
   - `AC += 30` per on-field NB entry, `+10` per on-field NB second, capped at 180; AC starts at 0.
   - The first time AC reaches 180: Counterstrike from then on (≈2 s switch: FM frozen, Cryo ignored, RES already 110%).
   - RES each tick: FM ≤ 10 → stopped (30%, Cryo −30%); else AC = 180 → 110%; else 270%.
   - Flag `broken` if FM ≤ 10 or AC = 180 ever happened in this loop.
3. Normal mode `[c+57.5, c+75)`: 10% if `broken`, else 80%.

Without timestamps (rates only): stopped from loop start + 22/(3r − 5) s if r > 5/3. Counterstrike from 18/u s after loop start if the
on-field NB fraction u is continuous from the start, or ≈ (180 − 30·entries)/(10·u) s in general. Take whichever comes first, then apply
the stop check again with FM at that time.

Suggested constants (cf. `MOONGECKO`):
`cycle 75, superTime 55, entry 5 (est.: StateChange ~2.5 + Super_Rush/RotateAtk_BS ~2.5), superStart 2.5 (est.), fmStart 32, fmMax 135,
fmTick 0.4, fmGain 2, fmPerCryo 3, fmStop 10, acMax 180, acEnter 30, acPerSecond 10, switch 2 (est.), energy 36 (first stop per Super)`.
New phases: `normal` res(80), `normalBroken` res(10). Counterstrike-stopped reuses `lowEnergy`.

## 5. Uncertainties

1. Transition lengths (StateChange, Super_Rush, RotateAtk_BS, SwitchMode/ThunderAtk_BS, *_AS) are not in the dump; ~5 s / ~2 s are guesses.
2. Whether the first (forced) StateChange starts the 75 s CD. Assumed yes (see §1).
3. `CGLJECJBFGG` (second predicate on the Cryo hit) is not decoded; assumed a generic damage-hit filter (no ICD).
4. Whether Cryo reaction DMG (Superconduct, Cryo Swirl) counts as a Cryo instance: likely, not verified.
5. Whether off-field NB counts (game text: active character only; predicate not decoded).
6. FM floor at 0 is assumed (AddGlobalValue min is not visible).
7. A leftover FM ≤ 10 from the previous Super could briefly apply the stopped RES during the next transition, before IceDetect reloads 32.
   Edge case; ignored.
8. Wiki vs game: the orb drop is once per Super phase (game file and in-game text), not once per combat (wiki).
