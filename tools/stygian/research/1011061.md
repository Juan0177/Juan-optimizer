## 1. Thundercall: the Electro ward

**Durability:** `_SHIELD_DURABILITY` = **1000** (40U) when `LeyLineChallenge_MonsterLevelHigh` is set. It is 300 (12U) otherwise.
- Source: ABL[27] `Monster_Chimera_Manticore_ElementShield`, onAdded branch.
- The overworld 300/200/150 by ward count applies only when the LeyLine value is none, so **every ward in Fearless/Dire is 1000**.
- SM: "40U Electro Shield"; W: `{{Elemental Shield Data|Electro|40}}` in Fearless/Dire (12U elsewhere).

**The ward modifier:** `UNIQUE_ElementShield_Electric` (element Electric, durability `_SHIELD_DURABILITY`). W adds that it places an immutable Electro aura on the boss. While the ward is up, every Cryo, Pyro, Hydro, Dendro or Anemo hit reacts with Electro.

**When it appears:** when the ElementShield ability starts. That is at the opening alert, and at the latest 5 s after entering combat (`ElementShield_FinalCheck`, duration 5, is the fallback trigger). **Estimate: ~2–3 s in.** Until then BornProtect is on.

**HP while warded:** untouched. The ward blocks the damage and a recorder mixin (`GNLGLAPDNFL`) adds it to `_SHIELD_ALL_DAMAGE`, plus `_StarDamage` for Stellar Glimmer tags. This is the same mixin as the Moongecko's ward. SM: "DMG taken during the shield-breaking process"; W: "DMG blocked by the Ward".

**Ward depletion per element** (GU of the hit × multiplier; 1 GU = 25 durability; no aura tax):

| attacking element | multiplier on the Electro ward | durability per 1U hit | source |
|---|---|---|---|
| Cryo (Superconduct / Stellar-Conduct) | **1.0** | 25 | GC `ANFHKLIHDPG.default` (no Electro←Ice entry, so 1); W template: Cryo = GU |
| Pyro (Overloaded) | **1.0** | 25 | GC default; W: Pyro = GU |
| Dendro (Quicken) | **1.0** | 25 | GC default; W: Dendro = GU |
| Anemo (Swirl) | **0.5** | 12.5 | GC default `aura Electric ← Wind ×0.5`; W: Anemo = 2×GU |
| Geo (Crystallize) | **0.5** | 12.5 | GC default `aura Electric ← Rock ×0.5`; W: Geo = 2×GU |
| Hydro | Only via Electro-Charged ticks: **0.4 GU = 10 durability per tick**, ≤1 tick/s (up to ~2/s with frequent applications) | 10/tick | W: "ceil(GU/0.4) ticks", i.e. 100 ticks for 40U |
| Electro, Physical | **0** | 0 | W (Electro column empty for an Electro ward) |

So ward durability/s = 25·(G_cryo + G_pyro + G_dendro) + 12.5·(G_anemo + G_geo) + 10·(EC ticks/s).

W: "weakest to Cryo, Pyro and Dendro … Stellar Glimmer Reactions are most effective" (the second point refers to the shockwave below).

**Does it come back?** Yes, always at 1000:
- (a) at the end of a Galeforce paralysis: `UNIQUE_Weak_Wind_Handler` onRemoved re-triggers the ElementShield ability if in combat;
- (b) after a successful absorb: second flight, then `LandAtk_Air` sets `_CHIMERA_MANTICORE_SHIELDRECOVER_` = 1, then AI skill 601 `ShieldRecover` (CD 10, priority 1) re-triggers the ward.

Sources: ABL[26], [14], [28]; MON skill 601.

**Damage recorder reset:** not explicit in the files. Assume it **restarts per ward**, as the mixin is on the ward modifier (the Moongecko is modelled the same way). Medium confidence.

## 2. The shockwave (SpecialAtk01, "Pulsating Blast")

- **Timing:**
  - AI skill 401: `initialCD` **12.5 s**, CD **30 s**, ground pose 101 only, priority 2 (above melee/ranged). Source: MON skills 401/402.
  - Skill set 1 (the Abyss variant, set by the IsAbyss ability) uses skill 402 with initialCD **1 s** instead. If Stygian used 26310506/07, the first shockwave would come right after the ward is up.
  - So: first at ~12.5 s after combat start (+ the wind-up), then about every 30 s while on the ground. It is not used in the air.
  - After a full ward → paralysis → flight → paralysis cycle (>30 s), it is ready again the moment the new ward is up.
- **Radiance check:** `SpecialAtk_StarReaction_Check` ticks every **0.2 s** from 50% of `SpecialAtk01_BS` through the `LOOP` (until normalized time 3.9). If `_IS_IN_STARMODE ≥ 1` (Radiance: Stellar Glimmer on the boss) at any tick:
  - the attack is interrupted (the remaining wave pulses are cancelled; the boss goes to `Hit_H`);
  - **2.1 s later** (`SpecialAtk01_BreakDelay`, duration 2.1) the ward loses **`_SHIELD_REDUCE` = 400 (16U)** in Fearless/Dire (100 = 4U elsewhere), if the ward is still up;
  - it drops Electro particles (game: drop 2020 ×18; SM: **6** Electro particles; W: "five, maybe six").
  - Source: ABL[10]; SM "16U … 6 Electro Elemental Particles"; W "16U instead".
- This removal **deals no damage**, so it adds nothing to the backlash. If it takes the ward to 0, the ward breaks normally (paralysis + backlash).
- **Modelling hint:** the check window lasts several seconds (its exact length is animation-bound and not in the dump). A team that keeps Radiance up most of the time makes every shockwave backfire. Otherwise the chance is roughly the uptime, a little higher because of the window.

## 3. Ward broken: backlash, Electro paralysis

**Trigger:** ward durability reaches 0 → `WeakElectricTrigger` → state `Weak_Electric_BS`. Entering that state applies `ElementShield_Broken_Damage` (Fearless/Dire only, `LeyLine == 1`). Source: ABL[27].

**Backlash formula** (one hit of True DMG: element None, fixed damage):

```
_SUM_ALL_DAMAGE = _SHIELD_ALL_DAMAGE × 0.3 + _StarDamage × 0.7
if _SUM_ALL_DAMAGE ≥ 0.8 × MaxHP:  _SUM_ALL_DAMAGE = 0.8 × MaxHP
```

- `_StarDamage` counts attacks tagged `StarSuperconductor`, `StarSuperconductorElectric`, `StarSuperconductorIce`, `StarSwirlIce` and `StarSwirlWind`.
- That equals **100% of the Stellar Glimmer DMG blocked + 30% of all other DMG blocked**:
  - SM: "True DMG equal to 100% of the Stellar Glimmer DMG + 30% of all other DMG taken";
  - W: "100% of the Stellar Glimmer DMG + 30% of all other DMG taken".
- **Model:** `backlashRatio = 0.3 + 0.7 × stellarShare`; **cap 0.8 × Max HP** (game only; SM and W give no cap). That is 8.60 M at Fearless and 18.68 M at Dire.
- The blocked DMG is computed at the boss's ward-phase RES (regular RES; see §5 for the possible permanent shred).
- Moongecko comparison: its mixin has two extra flags (`CMCJMGAHLJE`, `EKIEBAKLLJF`) and its community reading is "70% Geo + 10% other". This suggests those flags exclude the tagged part from the total there. The lion lacks them, so its total includes the Stellar part. This is consistent with SM and W, but it is inference.

**Electro paralysis:**
- `UNIQUE_Weak_Electric_Handler`: duration **12 s**, applied on entering `Weak_Electric_BS`. Its think timer at **8.111 s** fires `WeakElectricASTrigger` (the get-up animation). The boss acts again when the modifier ends at 12 s. Source: ABL[26].
- SM says "stunned for **13 s**". W gives no number ("briefly stunned" in the overworld).
- **Use 12 s for the RES window**, and treat ~13 s until it acts as SM's figure.

**Paralysis RES** (Fearless/Dire):

| element | value | how it adds up |
|---|---|---|
| Physical, Pyro, Hydro, Dendro, Geo | **−60%** | 10 − 70 |
| Electro | **−60%** | 50 − 70 − 40 |
| Cryo | **−120%** | 10 − 70 − 60 |
| Anemo | **−120%** | 50 − 70 − 60 − 40 |

- −70 to all: `SubHurtDeltaElectric = −0.7`.
- −60 to Cryo and Anemo: `SubHurtExtra`, set to −0.6 when `LeyLine` is set (0 otherwise).
- −40 to Electro and Anemo: `Weak_ExtraSubHurt` (`SubHurtLong = −0.4`), applied by the backlash modifier.
- Sources: ABL[26] `JPHEELFGNDA`, ABL[27]. Matches SM's "Stunned" column and W's Stygian "Paralyzed" row exactly. The overworld (no LeyLine) is −60 / −20 / −20, also on W.

**After it:** the handler's onRemoved sets `_CHIMERA_MANTICORE_LAUNCH_` = 1. AI skill 501 `Launch` (priority 1, precondition LAUNCH == 1) fires at once, and Galeforce begins. ABL[26], [13]; MON 501.

## 4. Galeforce: flight, vortex, Anemo paralysis

**When:** only after an Electro paralysis. Launch needs `_LAUNCH_`, which is set only when the Electro weak state ends (or on a reset). There is **no time or HP trigger**. A team that never breaks the ward never sees it, and also never damages the boss's HP after the opening.

**Flight:**
- `Launch` resets the air skills' CDs (1101/1301/1401/1501) and sets `AIRSTAGE` 1 (pose 202).
- Then `FlyAtk_Air` (priority 2): circles the arena centre and fires Gale Bolts every 0.3 s (normalized 0.45–0.82 of the tactic animation).
- Possibly `SpecialAtk02_Air` (Thunderstorm Chimeric Roar, priority 3).
- Then `Absorb_Air` (priority 4, initialCD 5 s after the CD reset).
- **Its length is animation-bound and not in the dump.** Estimate ~8–12 s from Launch to the vortex; calibrate on video.
- It can be hit: `HitBox_Air` / `PushCollider_Air` exist. In practice this is ranged/AoE-only damage.
- No ward: the damage goes to HP at regular RES.
- Sources: ABL[13], [15], [24]; MON 1101/1401/1501.

**Vortex (`Absorb_Air`):**
- It hovers at the arena centre. **5 Anemo Orbs** spawn at about ±60° 15 m, ±30° 25 m and 0° 12 m.
- `UNIQUE_Absorb_Air_State`: duration 11 s, think **9.5 s**. It needs **3** orbs absorbed: `ABSORB_COUNT ≥ 3` (watcher 2.5–5.5) leads to `Absorb_Success`; the charge bar max is 3.
- Sources: ABL[19], [20]; SM "absorb 5 … failed to absorb 3"; W "Each leftover orb will fill the gauge by 1/3".
- Ways it fails (paralysis follows):
  1. **Orbs destroyed:** a single Pyro, Electro, Hydro or Cryo hit destroys an orb (`Absorb_Air_Bullet_Logic` onBeingHit). Anemo, Geo, Dendro and Physical do nothing to orbs.
     - All **5** destroyed → `Absorb_KillAllBall` → paralysis **at once**.
     - ≥3 destroyed (so ≤2 can be absorbed) → paralysis at the **9.5 s** check.
  2. **Radiance on the boss** during `Absorb_Air_LOOP` (0.2 s ticks, from the end of its first loop to loop 14):
     - absorption stops (`_ABSORB_STARMODE_` = 1, the orbs die);
     - **2.1 s later** `StarModeTrigger` ends the vortex and the boss is paralysed.
     - Estimate ≈ 3–5 s after the vortex starts if Radiance is already up.
     - In the overworld and Abyss this also deals 15% Max HP self-damage. **In Fearless/Dire `_LOSE_HP_RATIO` is not set, so no HP loss.** ABL[19]; W "The HP lost effect … is removed".
- **If it absorbs 3:**
  - `Absorb_Success`: an Anemo AoE, `AIRSTAGE` 2 (pose 204), the air-skill CDs reset;
  - a second circling, possibly the roar, then `LandAtk_Air` (a landing slam that sets SHIELDRECOVER);
  - then `ShieldRecover`: **a new 1000 ward with no paralysis window.**

**Anemo paralysis:**
- `UNIQUE_Weak_Wind_Handler`: duration **16 s**, think **12.117 s** (get-up trigger). ABL[26]; W: "knocked down and stunned for 16 seconds".
- RES is the same as the Electro paralysis: all −60%, Cryo −120%, Anemo −120%, Electro −60%. This needs `Weak_ExtraSubHurt` to still be on; it is, see §5. Without it, Electro would be −20% and Anemo −80%. SM and W give a single paralysed row (above).
- At its end: **the ward regenerates** (1000), and the shockwave is ready again.

## 5. Other states, RES changes, uncertainties

- **Possible permanent shred:** `Weak_ExtraSubHurt` (Electro and Anemo **−40%**) has no duration and nothing ever removes it. Its special is named `SubHurtLong`. If it does persist, then from the first ward break on, **regular RES is Electro 10% and Anemo 10%**, and Fearless/Dire paralysis is always the values above.
  - It does not stack: the default stacking is Refresh. Medium-high confidence from the files.
  - Neither SM nor W mention this. Their "regular" column is the start-of-fight state.
  - **Verify in game** (Electro/Anemo hit after the first break vs before).
- **Out of reach:** no invulnerable state in the files. Lost uptime comes from:
  - the opening before the ward (+200% RES);
  - the flight and vortex (airborne; melee mostly can't reach);
  - the ward phases (damage blocked, banked into the backlash).
- **Monster variant / first shockwave:** 12.5 s if 26310505 (likely), 1 s if an IsAbyss variant.
- **Animation-bound times are not in the dump:**
  - the shockwave's Radiance window length and how long the wind-up takes before it;
  - Launch + circling length;
  - the vortex BS + first loop before its Radiance check;
  - orb travel time (when the 3rd orb would arrive);
  - the time from landing to the ward after a successful absorb.
- **Lower difficulties** (for completeness): ward 300, shockwave −100, `SubHurtExtra` 0 (paralysis all −60, Electro/Anemo −20), no backlash, no `Weak_ExtraSubHurt`.
- **Hydro on the ward:** the EC tick rate is the wiki's model (0.4 GU per tick). It is not in GC's reaction table, because EC is not a consuming reaction modifier.

## 6. Fight timeline (Fearless/Dire), as the model would run it

| t / step | state | HP damage | RES |
|---|---|---|---|
| 0 → ~2–3 s (≤5 s) | opening, BornProtect | to HP | 210% / Electro, Anemo 250% |
| ward up → broken (T_ward) | **ward**: 1000 durability, HP immune, damage banked | none | regular (Electro/Anemo 10% after the 1st break if the shred persists) |
| — during the ward | shockwave at ~12.5 s from start, then every 30 s from its last cast (ready at once after each full cycle). If Radiance is on in its window: −400 durability 2.1 s after detection. | — | — |
| break | backlash = min(0.3·A + 0.7·S, 0.8·MaxHP), true DMG | event | — |
| +0 → +12 s | **Electro paralysis** (acts again at ~13 s per SM) | to HP | all −60%, Cryo −120%, Anemo −120% (Electro −60%) |
| +12 s → ~+22 s (est.) | Launch, circling with Gale Bolts (roar possible) | to HP, ranged/AoE | regular |
| vortex 0 → ≤9.5 s | 5 orbs, needs 3 | to HP (hovering at centre) | regular |
| — Radiance on | fail at ~detection + 2.1 s | | |
| — all 5 orbs hit by H/P/E/C | fail at once | | |
| — ≥3 orbs hit | fail at 9.5 s | | |
| fail → +16 s | **Anemo paralysis** | to HP | as Electro paralysis |
| end | ward 1000 again → loop to "ward" | | |
| (success instead) | 2nd flight + slam + ShieldRecover → ward 1000, no paralysis | | |

**Team quantities to use:**

```
T_ward       = time until 25·(G_cryo+G_pyro+G_dendro)·t + 12.5·(G_anemo+G_geo)·t + 10·EC·t + 400·(backfired shockwaves) ≥ 1000
A            = DPS at the ward RES × T_ward
S            = stellarShare × A
backfire     ≈ Radiance on at the shockwave's wind-up
vortex fail  = Radiance uptime > 0 at the vortex, or enough H/P/E/C AoE hits to kill orbs
               (no hits of those elements and no Radiance → it succeeds)
```
